# 🌍 Global Store Sales Dashboard - Power BI

A comprehensive Power BI dashboard analyzing sales transactions for a global retail store with branches worldwide. This interactive dashboard provides stakeholders with detailed insights into sales performance across different geographical segments, shipping methods, and business metrics.

## 📊 Project Overview

This project delivers an end-to-end business intelligence solution for global store sales analysis. The dashboard enables stakeholders to make data-driven decisions by visualizing key performance indicators across countries, regions, markets, and cities.

## 🎯 Objectives

- Perform comprehensive data cleaning and preparation
- Create interactive visualizations segmented by country, region, and market
- Analyze shipping performance and distribution by ship mode
- Provide detailed sales reports across geographical hierarchies (city, state, region, market)
- Build an interactive, user-friendly dashboard for stakeholder presentations

## 📁 Dataset

**Source:** [Global Store Dataset](https://docs.google.com/spreadsheets/d/1Ez8RhO1rE2QikfdddOZ19eEZhN4r6eW7WHb9qB05T7E/edit?usp=sharing)

The dataset contains comprehensive sales transaction data from store branches worldwide, including:
- Sales transactions
- Geographic information (Country, Region, Market, State, City)
- Shipping details and modes
- Product categories
- Customer information
- Time-series data

## 🚀 Getting Started

### Prerequisites
- Power BI Desktop (Latest version recommended)
- Internet connection to access the Google Sheets dataset

### Installation Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/Devikrishna545/global_store.git
   cd global_store
   ```

2. **Access the Dataset**
   - Open the [Google Sheets dataset](https://docs.google.com/spreadsheets/d/1Ez8RhO1rE2QikfdddOZ19eEZhN4r6eW7WHb9qB05T7E/edit?usp=sharing)
   - Download as CSV or connect directly from Power BI

3. **Open Power BI File**
   - Launch Power BI Desktop
   - Open the `.pbix` file from the repository
   - Refresh the data connection if needed

4. **Explore the Dashboard**
   - Navigate through different report pages
   - Use filters and slicers for interactive analysis
   - Drill down into specific metrics
